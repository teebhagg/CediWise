# Send feedback

You use the app; we build it. Report bugs, request features, or say what confused you. Honest notes help most.

The HTML page is the form. It asks for:

- Category: Bug Report, Feature Request, or General Comment.
- Rating of your experience.
- Feedback text: at least 10 characters, up to 2000.
- Email, optional, for follow-up.

Submit it on the HTML page: https://www.cediwise.app/feedback
